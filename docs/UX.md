# Улучшение UX

## 1. Оценка ПО по атрибутам UX

### 1.1 Распознаваемость соответствия
Приложение представляет собой To-Do List, основной функционал соответствует ожиданиям пользователя. Однако, отсутствуют подсказки при первом запуске.

### 1.2 Обучаемость
Простота интерфейса позволяет быстро освоиться, но не хватает интерактивного туториала для новых пользователей.

### 1.3 Используемость (операбельность)
Интерфейс удобен, основные функции доступны, но есть недостатки в навигации между экранами.

### 1.4 Защита от ошибок пользователя
Нет подтверждения удаления задач, что может привести к потере данных.

### 1.5 Эстетика GUI
Цветовая палитра приятна, но шрифты и размеры кнопок требуют улучшения.

### 1.6 Доступность
Нет поддержки экранных дикторов и адаптации для слабовидящих пользователей.

## 2. Пути улучшения UX

1. **Добавить онбординг** с подсказками и интерактивным обучением.
2. **Улучшить навигацию**, добавив удобную навигационную панель.
3. **Добавить подтверждение удаления задач**, чтобы избежать случайных действий.
4. **Оптимизировать интерфейс**: увеличить кнопки, улучшить контрастность.
5. **Добавить поддержку доступности**, используя стандарты WCAG 2.0.
